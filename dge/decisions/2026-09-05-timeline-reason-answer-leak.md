# 新設合併の設問で、正解名を含む旧自治体名を問題文に出さない

## 決定

`scripts/question-types/timeline-reason.mjs` の merge 分岐で、問題文に列挙する旧自治体を
「正解（`ev.new.name`）を部分文字列として含まないもの」に限定する。

- 隠した旧自治体が1件以上ある場合、文面を `「A・B」が合併して誕生したのは？` から
  `「A・B」と合併して誕生したのは？` に変える。「と」は正解の自治体も合併の当事者だったことを示す。
- 隠した結果、表示できる旧自治体が0件になるイベントは出題しない。

判定に「同名（`===`）」ではなく「部分文字列を含む（`includes`）」を使うのは、
`timeline-merge-那賀町-2005-03-01`（「鷲敷町・相生町・**上那賀町**・木沢村・木頭村が合併して誕生したのは？」
正解 那賀町）のように、完全一致ではないが正解が問題文に現れるケースがあるため。
この条件により **「生成された全 timeline-reason 設問で `prompt.includes(answer)` が偽」** を
不変条件として保証できる。

## 境界

- `absorb` 分岐は変更しない（該当0件を実測で確認済み）。
- 誤答（distractor）の選び方・除外集合・`difficulty`・`tags`・`source`・`trivia`・`id` は変更しない。
- 設問データの再生成は `node scripts/build-quiz-sets.mjs` のみで行い、
  Wikidata などライブな外部ソースの再取得（`npm run build:data` 全体）は行わない。
- 他カテゴリのジェネレータ、UI、server.js には触れない。

## 理由

`docs/market/2026-08-22.md` は自治体変遷カテゴリを唯一の勝負所と結論している。その timeline-reason
741問のうち **189問（25.5%）で正解が問題文にそのまま書かれており**、merge に限れば 189/484 で約4割に達する。
問題文を読むだけで解けるので、設問として成立していない。

これは設計の見落としではなく実装の取りこぼしである。同じ `collectEvents` の merge イベントを扱う
`scripts/question-types/portmanteau.mjs:13` は `!ev.olds.some(o => o.name === ev.new.name)` で
同じケースを明示的に除外している。隣のジェネレータが持っている条件を timeline-reason だけが
持っていない。

修正しても出題数はほぼ減らない。実測で該当188イベントすべてに、正解名を含まない旧自治体が
1件以上残る（残り1件が73、2件が45、3件が32、最大11件）。出題不能になるのは
`[上湧別町・湧別町] → 湧別町` と `[有田町・西有田町] → 有田町` の2件だけで、741 → 739 問となる。

## 却下・保留

- **結果画面の正答数・振り返り・誤答復習（G-5）**: 保留。単体では最有力だが、
  vanished の 148問は正解自体が事実として誤り（`vanished-朝日町-北海道`、朝日町は山形・富山・三重に現存）で、
  復習機能は「正しく知っていたのに×になった問題」を優先的に反復提示する装置になる。
  誤問を先に潰す。
- **都道府県フィルタ（ご当地モード、G-12）**: 却下。`vanished.mjs:52` の誤答が全国プールなので
  「北海道編」では「4択のうち北海道らしい名前」を選ぶ消去法が成立し、same-name 57問は答えが
  都道府県名そのもの。誤答プールの県内化が前提で、抽象化だけ先行させると体験が悪化する。
- **北方領土6村の混入と古宇郡泊村の消失（G-4）**: 保留、別issueで追跡。修正には Wikidata の
  再取得が必要で、意図した修正と2026-08以降の上流ドリフトが同じ差分に混ざる。
  `build:data` に provenance（取得日・ソースcommit）が無いため切り分けもできない。
- **vanished の正解が他県に現存（G-2）・city-fact の僅差比較（G-8）**: 保留。同型の出題品質問題だが、
  修正案が一意に決まらない（G-2）か、独立した意味単位（G-8）。
- **tramli / tramli-appspec**: 不採用。ビルド時に走る純関数の生成条件を1つ足すだけで、
  永続状態・外部event・人間の承認を増やさない。

## 可逆性

変更は `scripts/question-types/timeline-reason.mjs` の1ファイルと、そこから決定論的に再生成される
`public/data/quiz/timeline-reason.json` / `all.json` のみ。`git revert` 一発で戻る。
DB も設定も外部状態も持たない。設問 `id` は変えないため、既存のIDを参照する外部があっても壊れない。

レビュアは `node scripts/build-quiz-sets.mjs` を実行して生成物がバイト単位で一致することを確認できる
（無改変の main でも差分ゼロになることを事前に確認済み）。
