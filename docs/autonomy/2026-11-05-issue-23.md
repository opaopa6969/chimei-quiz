PRのCIでは、今回の変更の依存不要な16回帰テストで除外処理と全quiz JSONを検証する。

最初のCI（[run 42028353506](https://github.com/opaopa6969/chimei-quiz/actions/runs/42028353506)）は、
npmが既存Git依存kazuをSSHで解決し、runnerにSSH鍵が無いため失敗した。
匿名HTTPSへ変更した[再実行](https://github.com/opaopa6969/chimei-quiz/actions/runs/42028569259)でも
Repository not foundとなり、公開取得可能という仮説は否定された。
最終的にCIは `node --test test/quiz-exclusions.test.mjs` に限定する。
全74テスト・再生成差分ゼロ・ビルドは既存依存の揃ったローカルで検証済み。
CIの資格情報追加・依存元の公開範囲変更・別実装の持ち込みを避けるための可逆な判断であり、
CIが全ビルドを検証するものではないことを明記する。

削除以外の変更がないことは、repoルートで次を実行して再確認できる。

```bash
python3 - <<'PY'
import json, pathlib, subprocess
base = '0d0419be7741a757a8455df5f972a41bdacbce7c'
for p in sorted(pathlib.Path('public/data/quiz').glob('*.json')):
    before = json.loads(subprocess.check_output(['git', 'show', f'{base}:{p}']))
    after = json.loads(p.read_text())
    ids = {q['id'] for q in after['questions']}
    assert after['questions'] == [q for q in before['questions'] if q['id'] in ids], p
    assert after['count'] == len(after['questions']), p
    assert {k: v for k, v in before.items() if k not in ('count', 'questions')} == {
        k: v for k, v in after.items() if k not in ('count', 'questions')}, p
    print(p.name, before['count'], '->', after['count'])
PY
```

バイト単位の再生成一致は次の手順で確認できる。

